# DCB ENG — Fabrication & Free Engineering Tools

This repository hosts the [DCB ENG website](https://dcb-eng.github.io/), featuring custom metal fabrication in Beauty Point, Tasmania, plus free engineering calculators for steel and pipe fabrication. The website is hosted on GitHub Pages.

## Free browser-based workshop tools

| Tool | What it does |
| --- | --- |
| [STEP / DXF to DSTV (NC1) converter](https://dcb-eng.github.io/step-dstv-converter/) | Experimental conversion of supported STEP steel sections, STEP plates and DXF plate geometry to DSTV NC1 CNC files; local browser processing. [Source and limitations](https://github.com/DCB-ENG/step-dstv-converter). |
| [Steel cutting & stock nesting optimiser](https://dcb-eng.github.io/steel-nesting/) | Plan steel bar cutting against stock lengths, quantities, saw kerf, offcuts and clamp allowances. |
| [Steel weight calculator](https://dcb-eng.github.io/steel-weight/) | Calculate Australian structural steel section weights, material take-offs and quantities for RHS, SHS, CHS, beams, channels, angles and plates. |
| [Metric bolt torque calculator](https://dcb-eng.github.io/bolt-torque/) | Estimate tightening torque for M3–M50 bolts by diameter, thread pitch, property class and dry/lubricated condition. General estimates only; manufacturer data takes precedence. |
| [Pipe bend calculator](https://dcb-eng.github.io/pipe-bend/) | Calculate bend geometry, bend allowance, bend start/end marks, springback estimates and segmented elbows. |
| [Pipe branch & fishmouth template calculator](https://dcb-eng.github.io/pipe-branch/) | Make CHS saddle/fishmouth and main-pipe opening templates, with 3D preview and print-scale wrap templates. |
| [Roll cage main hoop & brace generator](https://dcb-eng.github.io/roll-cage/) | Calculate main hoops, continuous front legs with two-bend schedules, windscreen headers, diagonal and rear stays, harness and side intrusion bars, individual straight-blank mark-out diagrams for every enabled tube (with bend marks or theoretical joint-centre references), plus labelled 1:1 fishmouth templates. Export a numbered per-tube cut list (RC-001 onward) and a separate bend mark-out list for every enabled tube, with start/centre/end bend positions, CLR, angles and mirrored front-leg clocking. Job prefixes, CSV and A4 printing are supported. If front legs are enabled, front side-bar joints use the modelled A-pillar; otherwise measured reference geometry is required. STEP export is planned, not yet available. |
| [Triangle & frame diagonal calculator](https://dcb-eng.github.io/triangle-calculator/) | Find missing angles and lengths, check frame diagonals and set out 3-4-5 squareness. |

These are free web tools intended to assist fabrication planning. Confirm calculations, print scale, geometry and machine compatibility before production, cutting or load-rated use.

## About DCB ENG

DCB ENG provides bespoke MIG/TIG welding, performance automotive fabrication, exhaust and intercooler piping, brackets and general metal fabrication in Tasmania.
