Direct browser STEP export

Create genuine analytic hollow-tube STEP solids in your browser using an OpenCascade WebAssembly CAD kernel. No Python installation required. This experimental page is limited to the main hoop, one front leg, and the main-hoop diagonal.

Open this from the calculator using Browser STEP lab, or select a saved geometry JSON file below.

The CAD engine downloads once on first use and can take some memory. No cage geometry is uploaded to DCB ENG servers. Your browser processes it locally.

Not production-ready: These are prototype CAD solids, not a certified safety cage or laser program. Open each STEP in ProCAM or another true B-rep CAD viewer and verify length, CHS OD/wall, surface continuity, fishmouth depths, datum orientation and end fit before manufacturing.

What the browser proof of concept does—and doesn't do

  1. Models actual circular bend arcs and round tube walls; no faceted STEP or renamed STL.
  2. Boolean-subtracts the full modelled main hoop from the front leg rear end and from the diagonal's two ends.
  3. Checks nonzero positive B-rep volume and STEP headers before downloads. It does not yet guarantee an independent STEP readback or ProCAM acceptance.
  4. Does not handle all 20 cage tubes, crossing reinforcements, mounting feet, weld gaps, ovalisation or tube-laser machine-specific setup.

If the browser CAD kernel fails, the existing Windows CadQuery/OpenCascade converter remains available. For a production release, further CAD round-trip and physical cutting tests are required.
