How the calculations work

Smooth bend: bend allowance (the centreline bend arc) = R × θ, where θ is in radians. Developed length = inlet straight + bend allowance + outlet straight. The tangent setback is R × tan(θ / 2) (not defined for a 180° return bend).

Segmented bend: select N welded joints, making N + 1 pieces. Each joint changes direction by θ / N; each mating cut is mitred by θ / (2N) from square. With k = R × tan(θ / (2N)), inlet / outlet piece centreline lengths are straight + k, and each middle piece is 2k. The joined straight centrelines form a polygon tangent to the reference circular bend of radius R.

Mitred piece length: for each mitred end, add (OD / 2) × tan(mitre angle) to the centreline for its longest edge, and subtract the same amount for its shortest edge. The total length is based on the straight-piece centrelines; this differs slightly from a smooth bend of the same radius.

Pipe schedules: ASME B36.10M nominal pipe sizes provide Schedule 5, 10, 30, 40, 80 and 160 where defined. Schedule changes wall thickness and inside diameter, not outside diameter. Metric CHS / tube dimensions remain independently selectable. Reference: ASME B36.10 pipe dimensions chart. Verify your purchased pipe specification before machining.

Springback model: when a material is selected, a simplified elastic unloading estimate uses M ≈ yield × plastic section modulus, Δκ ≈ M / (elastic modulus × I) for a circular tube. It ignores hardening, neutral-axis shift, ovalisation and machine/tooling effects; the predicted bender setting is a low-confidence planning guide, not an assured angle. Method selection keeps machine-specific calibration separate and provides process notes but does not apply unverified method multipliers.

Springback: After a test bend, measured loss is test bender setting − test released angle. Fixed-loss projection: target angle + measured loss. Optional proportional projection: target angle × test setting / test released angle. Both are first estimates, not material-property predictions; verify with a second bend.

Limitations: These are geometrical estimates for circular pipe, not production-certified bend data. No compensation for bend thinning, ovality, elongation, tooling, saw kerf, weld preparation, weld gaps or fit-up. Always check the first cut and compare against the machine / fabrication drawing.
